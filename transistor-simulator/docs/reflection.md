# Reflection — Lab 02: BJT DC Bias Web App

## สิ่งที่ทำ

สร้างเว็บแอป Flask สำหรับคำนวณ DC operating point ของ BJT
common-emitter voltage-divider bias โดยแยก logic วิศวกรรม
(`dc_bias.py`) ออกจาก HTTP (`app.py`) อย่างชัดเจน

## สิ่งที่ได้เรียนรู้

1. **การแยกชั้น (separation of concerns)** ทำให้ทดสอบสูตรไฟฟ้าได้โดยไม่ต้อง
   เปิดเซิร์ฟเวอร์ และทำให้แก้ UI กับแก้สมการแยกจากกันได้
2. **Thevenin equivalent** เป็นวิธีที่ตรงไปตรงมากว่าการเดาว่า IB ≈ 0
   และทำให้เห็นผลของ β ต่อจุดทำงานชัดขึ้น
3. **Validation ที่ขอบเขต** สำคัญพอ ๆ กับสูตร: R1/R2 เป็นศูนย์ทำให้หารด้วยศูนย์,
   β ติดลบทำให้กระแสติดลบ ซึ่งไม่มีความหมายทางฟิสิกส์
4. **Region check** ต้องระวังว่า saturation ที่คำนวณได้มาจาก linear model
   ค่าจริงจะถูก clamp ใกล้ `VCE_SAT`
5. **Unit conversion** ควรทำครั้งเดียวที่ขอบระบบ แล้วเก็บภายในเป็น SI
   เพื่อลดบั๊กจากการผสมหน่วย

## ปัญหาที่เจอ

- `python` บนเครื่องชี้ไปที่ Microsoft Store จึงต้องใช้ `py`
- Flask ยังไม่ติดตั้ง ต้องเพิ่ม `requirements.txt` และติดตั้งก่อนรัน
- การทำ `unittest discover` ต้องมี `tests/__init__.py` และใช้ `-t .`

## ข้อจำกัด

- เป็น DC bias เท่านั้น ไม่มี AC/transient
- `VCE_SAT` เป็นค่าคงที่ ไม่ได้เลือกตามเบอร์ทรานซิสเตอร์
- ไม่มีการบันทึกประวัติการคำนวณ

## ถ้าพัฒนาต่อ

- เพิ่มการเลือกเบอร์ BJT และดึงค่า `VCE_SAT`, `β` จาก datasheet
- เพิ่มกราฟ load line และ Q-point
- เพิ่ม export ผลเป็น PDF/CSV สำหรับรายงานแล็บ
- เพิ่มการเทียบกับ ngspice สำหรับ validation ที่เป็นอิสระจริง
